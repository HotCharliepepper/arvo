# ARVO × 마장동 R9 · VS Code 편집용

이 폴더는 고객용 R9 HTML과 같은 콘텐츠를 별도 파일로 나눈 **편집용 소스**입니다. 원본 R8·실제 운영 홈페이지는 변경하지 않았습니다.

## 1. 어디서 시작하나요?

1. ZIP을 압축 해제합니다.
2. VS Code → File → Open Folder에서 `vscode_project` 폴더를 엽니다.
3. `index.html`을 더블클릭해 브라우저에서 열거나 VS Code의 **Live Server** 확장으로 `Go Live`를 실행합니다.
4. 실행 후 상단 `궁금한 장면부터 살펴보세요` → 예약 비교/욕실 안내/선택 설문을 차례대로 눌러봅니다.

패키지에는 별도 npm 설치가 필요하지 않습니다. 다른 브라우저 환경과 공유를 검수하려면 Live Server로 로컬 주소를 쓰는 편이 좋습니다.

## 2. 무엇을 어디서 고치나요?

| 파일 | 역할 | 수정하기 좋은 곳 |
|---|---|---|
| `index.html` | 화면 순서·문장·정보 구조 | `<section id="...">` 각 섹션의 글 |
| `styles.css` | 컬러·글꼴·여백·반응형 디자인 | `:root` 색상 변수, 마지막 `R9 editorial refinements` |
| `app.js` | 클릭 후 화면 전환·그래프·선택 요약 | `const weeks`, `const keywords`, `guideActive`, `R9 interaction hints` |
| `assets/` | R8에 내장돼 있던 실제 이미지·연출 시안 | 사진만 교체할 경우 같은 파일명으로 교체 |
| `build.mjs` · `package.json` | 단일 HTML 생성 | 터미널 `npm run build` → `dist/index.html` |

숫자 수정 시 표시 수치뿐 아니라 `app.js`의 주간 배열, 합계·기간 설명을 반드시 함께 확인하세요. 검증되지 않은 수치를 게시용으로 바꾸지 않습니다.

## 3. 직접 눌러볼 요소

- 상단 안내 카드: 예약 비교 / 욕실 안내 / 가족분들의 선택으로 이동
- 예약 막대: 주간 수치와 아래 문장이 바뀜
- 키워드: 마장동과 아르보를 전환해 질문·발행 방향 변경
- 예약 전 / 투숙 중: 객실 기대 장면 ↔ 욕조 현장 사진 전환
- 욕조 안내: 무안내 → 현장 메모 → 개선 시안 (모바일은 다음 버튼)
- 객실 사진·음식: A/B, 음식 사진 썸네일 전환
- 설문 Q1~Q4: 선택 요약 자동 갱신, 메모 복사(외부 전송 없음)

## 4. 운영·권리 확인

- 이 파일은 **공유용 검토 시안**이지 운영 홈페이지가 아닙니다.
- ‘여기어때 174건 / NOL 129건’은 2026-10-18~11-14 동일 구간의 두 자료를 잠정 비교한 값입니다. 실제 예약 채널명, 취소 포함 여부, 수익성은 현장에서 확인해야 합니다.
- 연출용 인물 사진은 실제 투숙객 촬영이라고 표시하지 않습니다.
- 욕조 조작법은 수전 실물과 안전 주의사항 확인 전에는 객실에 부착하지 않습니다.
- Google/네이버/OTA 후기 작성과 증정품을 교환 조건으로 연계하지 않습니다.
- 리뷰 QR은 연결되지 않은 자리표시자입니다.
- 기존 계약 범위를 넘는 작업은 제작 사양·승인·실비를 별도로 합의합니다.
- 외부 발송·게시·운영 배포·실제 결제 기능은 포함하지 않았습니다.

## 5. 고객용 단일 파일 만들기

VS Code에서 문장이나 디자인을 수정한 뒤 터미널에서 아래 명령을 실행합니다. `npm install`은 필요하지 않습니다.

```powershell
npm run build
```

그러면 `dist/index.html`이 생성됩니다. 이 한 파일만 전달하면 사진·디자인·인터랙션이 함께 열립니다. `index.html`(편집용)과 `dist/index.html`(전달용)은 목적이 다릅니다. **편집용을 기준 원본으로 보존하세요.** 외부 배포는 고객 승인 후 진행합니다.
